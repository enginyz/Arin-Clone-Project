# 🖥️ Arin Clone Project  

Bu proje, [https://gega-project.netlify.app/](#) temel alınarak **HTML, TailwindCSS ve JavaScript** ile oluşturulmuş bir **klon tasarım projesidir.**  

## 🚀 Özellikler  
✅ **Orijinal site tasarımına sadık kalarak birebir klonlama**  
✅ **TailwindCSS kullanılarak optimize edilmiş stil yapısı**  
✅ **Duyarlı (responsive) tasarım ile mobil uyumluluk**  
✅ **JavaScript ile temel interaktif özellikler**  

## 📌 Kullanılan Teknolojiler  
- **HTML**  
- **TailwindCSS**  
- **JavaScript (ES6+)**  

## 🛠️ Kurulum ve Çalıştırma  
Projeyi klonla ve çalıştır:  
```sh
git clone https://github.com/enginyz/Arin-Clone-Project.git
```

✅ Daha sonra index.html dosyasını açarak çalıştırabilirsin!
